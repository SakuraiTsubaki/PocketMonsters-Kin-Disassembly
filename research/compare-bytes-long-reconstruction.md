# Pocket Monsters Kin CompareBytesLong

The Japanese release `kin-jp-rev0` is the origin reference. All 8 cataloged releases (Japanese, Korean, English, German, Spanish, French, Italian) contain exactly one ROM0 implementation with the same fifteen-byte code hash. The routine uses a 16-bit BC count and reports equality through carry. Evidence records release identity and address without ROM bytes. Korean precedes English where available; release status is unchanged.
