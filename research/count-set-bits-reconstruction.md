# Pocket Monsters Kin CountSetBits

The Japanese release `kin-jp-rev0` is the origin reference. All 8 cataloged releases (Japanese, Korean, English, German, Spanish, French, Italian) contain exactly one ROM0 implementation of the same bit-count loop. The release-specific wNumSetBits address and complete routine hash are recorded without ROM bytes. Korean precedes English where available; release status is unchanged.
